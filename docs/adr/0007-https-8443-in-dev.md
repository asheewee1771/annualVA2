# The back end serves HTTPS on 8443 in local development

Status: accepted

HSTS, `Secure` and `SameSite` cookies and the OIDC redirect behave as in production only over TLS, and Keycloak in the mock stack fetches the app's JWKS over HTTPS. The back end serves TLS locally from a self-signed EC P-521 keystore (`dev-keystore.p12`, generated by `scripts/gen-dev-keys.sh`) and Vite proxies to it. The `ci` profile uses plain HTTP with a non-secure cookie so Testcontainers-based tests need no certificates.

Consequences: a one-time browser trust prompt for the two local certificates; Playwright ignores HTTPS errors only against the local stack; `localhost` is the only host name used, so the pinned HSTS never affects a real site.
